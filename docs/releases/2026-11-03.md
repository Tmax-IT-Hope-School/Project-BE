## 1. 배포가 밀린 이유

`render.yaml` 이 `autoDeployTrigger: checksPass` 라서 **main 의 GitHub Actions 검사가 통과해야 배포**됩니다.

- 10/31 에 조직의 Actions 무료 분량이 다 떨어져서 검사가 시작도 못 하고 실패했습니다. (2초 실패, 단계 0개, "recent account payments have failed or your spending limit…")
- 달이 바뀌면 분량은 다시 채워지지만, **이미 실패한 검사를 저절로 다시 돌리지는 않습니다.** 새 커밋도 없어서 Render 가 계속 기다렸습니다.
- 그래서 11/3 까지 과목 쌤이 옛 지시문대로 문제를 번호 목록 글로 썼습니다. (#473 이 안 나간 상태)

**풀린 방법:** 검사를 다시 돌리니 통과했고, 재실행만으로 Render 배포도 시작됐습니다. 통과 약 4분 뒤 `GET /api/v1/auth/school-class` 가 404 에서 401 로 바뀌었습니다.

```bash
gh run rerun <실패한 main 실행 번호> --repo Tmax-IT-Hope-School/Project-BE
```

재실행해도 몇 초 만에 실패하면 아직 한도가 안 풀린 것입니다. 조직 결제 설정을 보거나 Render 관리자에게 Manual Deploy 를 부탁합니다.
